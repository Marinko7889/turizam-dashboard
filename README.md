# Turizam u Hrvatskoj: dashboard

 Analizu noćenja i prognozu sam radio u Pythonu, a ovo je web prikaz rezultata
## Stranice

- **Pregled**: ključne brojke, noćenja po mjesecima i godinama s filterom razdoblja. Filter se sprema u URL (`?od=2018&do=2024`), pa se link može podijeliti.
- **Sezona**: usporedba dviju godina po mjesecima i udio špice u odnosu na predsezonu i posezonu kroz godine.
- **Prognoza**: prognoza za idućih 12 mjeseci s prekidačem između tri modela (baseline, SARIMA, LightGBM) i usporedba njihove točnosti.
- **Uskrs**: za odabranu godinu računa datum Uskrsa i Duhova i pokazuje kako Uskrs utječe na noćenja u travnju.
